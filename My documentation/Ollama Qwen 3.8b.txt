test_cases = [

### **5. Measure Metrics**  
- **Accuracy**: Compare Fortis’s response to the expected description.  
- **Hallucination Rate**: Check for fabricated or irrelevant information.

```python
results = []
for case in test_cases:
    start_time = time.time()
    response = requests.get(f"{base_url}?technique={case['technique_id']}")
    elapsed_time = time.time() - start_time
    result = {
        "technique": case["technique_id"],
        "response": response.json(),
        "elapsed_time": elapsed_time,
        "accuracy": "Pass" if response.json()["description"] == case["expected_description"] else "Fail"
    }
    results.append(result)
```
